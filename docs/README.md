# Documentation

The suite-wide pages of Flatwater. Each plug-in's own documents (README, RESEARCH, MEASUREMENTS, NULLTESTS) are in
its folder under `plugins/`; the root [MEASUREMENTS.md](../MEASUREMENTS.md) and [RESEARCH.md](../RESEARCH.md) index
them.

| Page | What it holds |
|---|---|
| [BUILDING.md](BUILDING.md) | the requirements and the build commands per platform |
| [results.md](results.md) | the null-test results of every plug-in against its original |
| [validation.md](validation.md) | the validation state of every plug-in: the ports and learned blocks, the editors, the listening tests, what the unit tests cover |
| [improvements.md](improvements.md) | what each plug-in does not yet match, and what would close it |
| [learned-blocks.md](learned-blocks.md) | how a plug-in replaces one stage with a small network of our own weights |
| [screenshots/](screenshots/README.md) | the editor images the READMEs show, and how the snapshot tools make them |
| [branding/](branding/) | the suite's banners, icon, social preview and colours |
